Zepto Inventory & Sales Dashboard

An interactive **Excel dashboard** developed to analyze Zepto's sales, inventory, stock, and delivery performance. The project transforms raw data into meaningful KPIs, Pivot Tables, charts, and interactive visualizations to support quick business insights.

🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning & Analysis
* Dashboard Design

📊 Key Features

* Sales and inventory performance analysis
* Product category-wise analysis
* Stock and reorder quantity tracking
* Delivery status analysis
* Interactive filters using slicers
* KPI cards for quick insights

📁 Dataset

The dataset contains **10,000 records** covering the period from **January 2024 to June 2024**, with multiple product categories and sales/inventory-related attributes.

🎯 Objective

To convert raw Zepto inventory and sales data into an interactive dashboard that makes it easier to understand business performance and identify useful trends.

📌 Project Outcome

The dashboard provides a clear visual overview of **sales, inventory, stock levels, reorder requirements, and delivery performance** using Excel-based analytics and visualization techniques.
